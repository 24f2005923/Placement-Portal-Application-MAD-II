# Placement Portal Application

Frontend-only placement management system built with Vue 3, Bootstrap 5, and Bootstrap Icons.

## Run

```bash
npm install
npm run dev
```

## Included Screens

- Authentication: login, forgot password, reset password
- Admin portal: dashboard, students, companies, drives, reports, settings
- Company portal: dashboard, registration, profile, drive management, applications, interviews, results
- Student portal: dashboard, registration, profile management, resume upload, drives, applications, history

## Notes

- Demo data is static and lives in `src/data/demoData.js`
- Shared layout and utility components live in `src/layouts` and `src/components/common`
- Routing is defined in `src/router/index.js`
